GATHERWELL — ANDROID STUDIO PROJECT

1. Extract this ZIP to C:\Users\LENOVO\gatherwell-app
2. Open that folder in VS Code, then open a Command Prompt terminal.
3. Run these one at a time:
   npm install
   npm run dev
   (Open the Local URL to check the app. Ctrl+C stops the server.)
   npm run android:sync
   npm run android:open

Android is already added. DO NOT run cap add android again.
Requires Node 22.12+ and a current Android Studio compatible with Capacitor 8.
If npm reports an unsupported Node version, update Node first.
